      Run it yourself

      This same rehearsal runs on your machine in about two minutes. You need Node 22 and no accounts.

      git clone https://github.com/puneetnith28/Loopback.git
cd Loopback
npm ci
npm run build
npm run demo

      Where Switch fits

      In real use, all of this happens in Switch rooms. Switch delivers every command, tells the gate who really sent it, and is the only way the gate reaches its agents.
