Why it's needed

Coding agents write fixes in minutes. Trusting them is the hard part.

One more commit lands after "looks good".

An approval names a full commit. Any new commit voids the evidence.

An agent says its tests passed when they never ran.

The gate trusts GitHub's CI results and a signed report tied to one run and one commit.

A public bug report carries instructions aimed at the agent.

    What each part of Switch does here

    What Switch providesWhat Loopback does with itWithout it

    GitHub is the source of truth for code. Switch is the source of truth for who said what, and where. The button on this page doesn't stop a server, because nothing here is running. It shows what you would see, and the refusal above is the gate's own wording, from starting it with Switch unreachable.

    Implementation

    How it's built

    A Node 22 and TypeScript service connects to Switch as an agent, keeps its state and audit log in SQLite, and is the only identity allowed to merge on GitHub.

    How this page works

    On this pageHow it's made
    Chat replies from the gateRecorded from the gate's real router, permissions, state machine and merge policy (apps/switch-gate/src/demo/rehearsal.ts), which check 16 outcomes as they run.
    Evidence consoleThe real React app from apps/console. It reads responses recorded from the real API in apps/console-api, taken at each step of that run, including the settings the rehearsal recorded as the gate does.
    TerminalWhat npm run demo printed during that run. Setup commands come from docs/setup.md.
    Team chat layoutDrawn after Slack's layout; it is not a capture of Slack. Only the recorded messages get answers. The live runs so far used Mattermost, and Slack is prepared but not yet run live.
    Switch Console screensIllustrations unless marked as screenshots. Field labels come from the real template file.
    The Switch buttonSwitches this page to what happens with no Switch: messages aren't delivered, no step can run, and the console shows no case. The refusal text is the gate's real wording, and a test fails if it changes in the code.
    The buildnpm run demo:page (scripts/build-demo-page.mjs). It writes nothing if the rehearsal fails.

    Run it yourself

    This same rehearsal runs on your machine in about two minutes. You need Node 22 and no accounts.

    git clone https://github.com/puneetnith28/Loopback.git
cd Loopback
npm ci
npm run build
npm run demo
